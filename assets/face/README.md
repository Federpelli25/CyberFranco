# Asset faccia opzionali

Inserire qui PNG trasparenti denominati `idle.png`, `blink.png`,
`listening.png`, `thinking_01.png`, `thinking_02.png` e `reveal.png`.

Gli asset vengono precaricati e scalati mantenendo le proporzioni. Se uno o più
file non sono disponibili, CyberFranco usa automaticamente il volto vettoriale
Qt integrato.
