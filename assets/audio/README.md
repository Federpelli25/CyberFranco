# Audio locale del personaggio

Inserire esclusivamente file locali `.wav` o `.mp3` nelle cartelle seguenti:

- `thinking/`: frasi scelte casualmente durante THINKING;
- `awaiting/`: riservata a eventuali clip singole future;
- `reveal/`: annunci delle squadre referenziati da `config/teams.json`;
- `system/`: prima traccia disponibile usata da TEST AUDIO.

I file definitivi non sono inclusi. Se una cartella o una clip non è presente,
il flusso grafico continua in silenzio.
